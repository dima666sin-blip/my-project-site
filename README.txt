ГОТОВЫЙ ВАРИАНТ ДЛЯ ПУБЛИКАЦИИ В ИНТЕРНЕТЕ

Файлы:
- index.html — сайт со всеми тремя изображениями.
- server.py — сервер сайта и отправки заказов в Telegram.
- render.yaml — готовая настройка Render.
- requirements.txt — зависимости (сторонние библиотеки не нужны).
- config.py.example — пример локальной настройки.
- .gitignore — не даёт случайно загрузить локальный токен.

ПУБЛИКАЦИЯ ЧЕРЕЗ RENDER + GITHUB

1. Создайте новый репозиторий на GitHub.
2. Загрузите ВСЕ файлы из этой папки в репозиторий.
3. Не загружайте config.py с реальным токеном.
4. На Render выберите New -> Blueprint.
5. Подключите репозиторий GitHub и выберите render.yaml.
6. При первом создании Render попросит значение BOT_TOKEN.
7. Вставьте НОВЫЙ токен от BotFather.
8. CHAT_ID уже установлен: 8976917219.
9. Дождитесь Deploy.
10. Render выдаст публичную ссылку вида https://имя.onrender.com.

ВАЖНО:
- Секретный BOT_TOKEN не должен находиться в GitHub.
- Для Render сервер использует 0.0.0.0 и переменную PORT автоматически.
- Перед тестом откройте бота в Telegram и отправьте ему /start.
- После успешной отправки заказа сайт переводит покупателя на страницу оплаты.

ЛОКАЛЬНЫЙ ЗАПУСК

Для запуска на компьютере создайте config.py рядом с server.py:
BOT_TOKEN = "НОВЫЙ_ТОКЕН"
CHAT_ID = "8976917219"

Затем:
python server.py

И откройте http://127.0.0.1:8765
